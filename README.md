## `❯ whoami`

DevOps & Cloud Engineer from Santo Domingo, Dominican Republic. I build and run
Kubernetes platforms on AWS and Azure, and self-host the rest on a K3s homelab.
Infrastructure as Code, GitOps, observability — turning manually-managed sprawl
into platforms teams can run themselves.
